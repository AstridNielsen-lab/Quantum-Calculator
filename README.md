# Quantum Calculator with AI

## Descrição
Quantum Calculator é uma calculadora avançada que integra Inteligência Artificial para facilitar cálculos matemáticos. Os usuários podem inserir expressões matemáticas por meio de texto ou fala, tornando a experiência mais intuitiva e acessível.

## Funcionalidades
- Suporte para entrada de cálculos via digitação ou comando de voz
- Modo de IA para cálculos avançados
- Opção de leitura em voz alta dos resultados

## Como Usar
1. Insira uma expressão matemática digitando ou falando.
2. Escolha o modo de cálculo padrão ou habilite o modo IA para análises mais avançadas.
3. Receba o resultado e, se necessário, utilize a leitura em voz alta para acessibilidade.

## Tecnologias Utilizadas
- JavaScript
- AI Integration
- Interface responsiva
